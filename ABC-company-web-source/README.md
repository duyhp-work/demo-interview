# ABC株式会社 Web Demo

架空企業「ABC株式会社」のコーポレートサイト用デモソースです。

## Reference

構成・情報設計は https://www.nk-gr.co.jp/ の公開ページを参考にしています。
参考にした主な構成：
- ホーム
- Works / 納入実績
- Company / 会社概要
- Contact / お問い合わせ
- Privacy Policy / プライバシーポリシー
- Worksの3系統：大型機械加工、ステンレス・アルミ製品、その他大型製缶製品

## Important

- 会社名、代表者、住所、電話番号、メールアドレス、設立、資本金、従業員数などはすべて架空です。
- 本サイトはデモ用途です。
- お問い合わせフォームは実際には送信されません。
- 写真はABC株式会社を想定した工場・金属加工のイメージです。
- nk-gr.co.jp のHTML/CSS/JSをコピーしたものではありません。
